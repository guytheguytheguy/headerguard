## Product Summary

HeaderGuard is a security header scanner and monitor for web applications. It scans any URL against 10 critical HTTP security headers, assigns a weighted letter grade (A+ to F), and generates framework-specific fix code so developers can correct configuration in one deployment cycle. The Pro tier adds daily monitoring, Slack/email alerts on grade changes, a REST API for CI/CD integration, and embeddable SVG badges.

**Stack:** Next.js 15, React 19, TypeScript, Tailwind CSS 4, Supabase Auth, Stripe
**Deploy:** https://headerguard.agenticnode.io
**Pricing:** Free (unlimited scans) + Pro at $9/month
